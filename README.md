# CPP Revision Setter

Sets the 'Standard revision' selection to 'C++23' on page load, so you don't have to!

DISCLAIMER: This is for personal use, so is implemented in a fairly rudimentary way and is brittle to changes in the page structure. An astute reader will surely find ample opportunity for a more robust implementation just on first glance.

## Install

1. Navigate to `chrome://extensions`
2. Enable developer mode
3. Click 'Load unpacked'
4. Navigate to and select this directory

This should add the project as an extension in your Chrome browser.
